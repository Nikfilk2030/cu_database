# Стенд домашней работы ClickHouse

Полная инструкция запуска, загрузки и повторного использования стенда находится в разделе **«Подготовка стенда»** задания, перед заданием 1. Файл задания выдан отдельно в LMS в формате PDF или Markdown.

Стенд использует ClickHouse **25.8.33.6**. Для запуска нужен работающий Docker с Compose; Docker Desktop необязателен.

1. Скачайте отдельный файл `listening_events.csv.gz` из LMS: это **10 000 000 событий**. Поместите его в папку `data` рядом с `compose.yaml`. Если после распаковки ZIP папки `data` нет, создайте её. Gzip распаковывать не нужно.
2. В терминале из папки с `compose.yaml` выполните `docker compose up -d --wait`.
3. Откройте встроенную страницу `http://localhost:8123/play`. Пользователь — `student`, пароль — `takt`.
4. Выполните первоначальную загрузку и проверки из задания. Если порт занят или запуск не удался, обратитесь к разделу «Подготовка стенда» в задании.

`00_prepare_source.sql` дословно повторяет SQL первоначальной подготовки из раздела «Подготовка стенда». Выполняйте команды по одной; повторный запуск отдельного INSERT удваивает данные. Для повторной подготовки используйте весь блок сброса и загрузки.

В репозиторий сдачи добавьте свой SQL, README, результаты и объяснения. Файл событий и содержимое Docker-тома в Git не добавляйте; текст задания переносить в репозиторий не требуется. Стенд с данными удобно держать отдельно от репозитория решения.
